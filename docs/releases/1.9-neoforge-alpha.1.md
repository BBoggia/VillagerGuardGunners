# Villager Guard Gunners 1.9-neoforge-alpha.1

This is the first Minecraft 1.21.1 NeoForge alpha of Villager Guard Gunners.
It brings the 1.9 feature set to the unofficial TaCZ NeoForge port, including
guard gun combat, commands, supplies, Quartermasters, medical care, and village
buildings.

## Highlights

- Guards can use TaCZ guns, reload from their ammo slots, switch to backup
  pistols, and follow configurable combat and accuracy settings.
- Guard Orders, Orders Ledgers, squads, Squad Command Ledgers, and saved patrol
  routes are available on NeoForge.
- Village Armories and Quartermasters support guard resupply, equipment
  loadouts, management overviews, bulk changes, and villager trades.
- Medical pouches, medic guards, downed casualties, treatment, Recovery Cots,
  and casualty transport are available through their existing settings.
- Recipes, loot, saved equipment, ledgers, and village structures use Minecraft
  1.21.1 formats. Guard inventories, trading, treatment, and gun state support
  multiplayer synchronization.
- The optional Village Buildings companion datapack has a separate Minecraft
  1.21.1 version. It includes vanilla villages and integrations for CTOV, Moog's
  Missing Villages, Tidal Towns, and Sky Villages. Missing providers remain inactive.

## Fixes

- Follow and patrol requests check current permissions, distance, the open
  guard inventory, and configured Hero of the Village requirements. Unauthorized
  requests cannot take ownership of another player's guard or start a remote patrol.
- Fully absorbed hits no longer interrupt medical care or shorten casualty
  timers. Partial absorption consumes the extra hearts and applies only the
  remaining damage.
- Guard inventory follow and patrol icons display correctly, and patrol toggles
  work after reopening the inventory.
- Village Armory access text fits above the ammo slots. Long squad names show
  their full text on hover.

## Requirements

This build requires Minecraft 1.21.1, Java 21, and **these exact versions**:

- **NeoForge:** 21.1.233
- **Guard Villagers:** 2.4.12
- **[Unofficial TaCZ NeoForge Port](https://www.curseforge.com/minecraft/mc-mods/tacz-1-21-1):** 1.1.8-hotfix-r7
- **Fzzy Config:** 0.7.7+1.21+neoforge
- **Kotlin for Forge:** 5.12.0

## Updating

When moving from Minecraft 1.20.1, start a new 1.21.1 world. Install Villager
Guard Gunners and all four required dependency mods on both client and server.
The unofficial TaCZ port does not support TaCZ world data
from Minecraft 1.20.1. Follow its gun-pack compatibility instructions when using
custom packs. The existing Minecraft 1.20.1 Forge release remains separate.

For redesigned village buildings, use the **Minecraft 1.21.1** companion ZIP,
enable Village Defense Building generation, and restart. Buildings appear in
newly generated villages. The Minecraft 1.20.1 building packs are not the correct
download for this build.

## Alpha Status

This is an early testing release. Wider modpack combinations, difficult terrain,
long-running servers, and performance at scale still need validation. Report
issues with logs, exact mod versions, and steps to reproduce them.

Sky Villages 1.0.6 has an existing item-frame placement warning in one of its
templates. The same warning occurs without Villager Guard Gunners installed.
