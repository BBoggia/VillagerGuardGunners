# Villager Guard Gunners 1.9.2

Forge hotfix for Minecraft 1.20.1. This update fixes a crash when firing guns
with TacZ:Arcana installed.

## Highlights

- Fixed the firing conflict between Villager Guard Gunners and TacZ:Arcana that
  could crash the game or server shortly after entering a world.
- Guards retain per-round friendly-fire checks and preserve ammo when those
  checks refuse a shot. Arcana's normal burst-fire behavior remains active.

## Compatibility

Tested with TaCZ **1.1.8-hotfix2**, both with and without TacZ:Arcana **1.1.4**.
Player firing, guard firing, and reloading were checked in normal Forge client
and server installations. This hotfix addresses the firing conflict; Arcana's
special ammo and altered projectile trajectories still need separate validation.
Arcana remains optional, and no additional dependency is required.

## Updating

Replace the previous Villager Guard Gunners JAR on both client and server, then
restart. Keep your existing configuration files, worlds, and building datapacks.
No configuration reset or gun-pack edits are required.

## Requirements

- Minecraft **1.20.1**, Java **17**, and Forge **47.4.10 or newer 47.x**.
- Guard Villagers **1.20.1-1.6.19**.
- Timeless and Classics Zero (TaCZ) **1.1.8 or newer for Minecraft 1.20.1**.
- Fzzy Config **0.7.6 for Minecraft 1.20.1**.
- Kotlin for Forge **4.12.0**.

Install the mod and all four required dependencies on both client and server.
