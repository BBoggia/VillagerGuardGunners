# Villager Guard Gunners 1.8.1

Version 1.8.1 updates TaCZ compatibility for Minecraft 1.20.1.

## Highlights

- Accepts TaCZ **1.1.8 and newer**, including **1.1.8-hotfix2**.
- Removes the exact-version requirement that prevented loading with newer TaCZ releases.

Gameplay, configuration defaults, and village building datapacks are unchanged from 1.8.

## Updating from 1.8

Replace the Villager Guard Gunners JAR on both client and server, then restart.
Keep your existing configuration files and building datapacks.

Newer TaCZ versions are allowed to load. Future TaCZ API changes can still require
an add-on update.

## Requirements

- Minecraft **1.20.1**, Java **17**, and Forge **47.4.10 or newer 47.x**.
- Guard Villagers **1.20.1-1.6.19**.
- Timeless and Classics Zero (TaCZ) **1.1.8 or newer for Minecraft 1.20.1**.
- Fzzy Config **0.7.6 for Minecraft 1.20.1**.
- Kotlin for Forge **4.12.0**.

Install the mod and all four required dependencies on both client and server.
