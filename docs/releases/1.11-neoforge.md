# Villager Guard Gunners 1.11-neoforge

Compatibility update for Minecraft 1.21.1 and official TaCZ 1.2.0.

## Highlights

- Replaced the unofficial TaCZ NeoForge port dependency with official TaCZ 1.2.0.
- Fixed the world-join crash caused by the changed TaCZ gun-pack synchronization
  API. TaCZ now handles compression and packet splitting itself.
- Updated guard firing and draw timing to use TaCZ's clock, including when a
  single-player world is paused.
- Updated firing hooks for TaCZ's new callbacks and post-fire events while
  retaining per-round friendly-fire checks and compatibility with other hooks.
- Added Marksman tactics to the default mapping for TaCZ's new `dmr` category.
  Existing custom maps are preserved; add `dmr = "MARKSMAN"` if it is missing.

## Updating

Update Villager Guard Gunners on both client and server. Replace the unofficial
TaCZ port with `tacz-neoforge-1.21.1-1.2.0.jar` from the official TaCZ project;
do not install both. This build requires exactly TaCZ 1.2.0. That dependency is
currently marked Beta by its authors.

Keep a backup when updating an existing world. Older gun packs can require
TaCZ's `/tacz convert universal` tool to generate Minecraft 1.21.1 overlays.
Gun-pack conversion is separate from upgrading an entire Minecraft 1.20.1 world.
No companion Village Buildings datapack update is required for these changes.

## Requirements

- Minecraft 1.21.1 and Java 21.
- NeoForge 21.1.233 or newer 21.1.x.
- Guard Villagers 2.4.12.
- Official TaCZ 1.2.0 for NeoForge 1.21.1.
- Fzzy Config `0.7.7+1.21+neoforge` or `0.7.7+fix1+1.21+neoforge`.
- Kotlin for Forge 5.12.0.

## Known dependency issue

Official TaCZ 1.2.0 can log a missing `tacz:blood_strike_1` reference in the
`minecraft:placeable` tag. This also occurs with TaCZ installed alone. It did
not prevent startup, joining, firing, or reloading in the checks for this release.
