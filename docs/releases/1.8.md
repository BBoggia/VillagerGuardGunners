# Villager Guard Gunners 1.8

Version 1.8 adds configurable guard accuracy, improves firing safety, and supports
a single optional building datapack for all supported village types.

## Highlights

- **Configurable accuracy.** Set guards' added aim error from 0–10 degrees and
  choose eye-level or center-mass targeting.
- **Separate player settings.** Adjust accuracy against players without changing
  how guards aim at mobs. In Fzzy Config, enable **Override Against Players**
  under **Combat → Guard Accuracy**. Start with **Aim Error Against Players = 2.0** and
  **Aim Point Against Players = Center Mass**, then adjust for your server.
- **Unchanged defaults.** Guards start with zero added aim error and eye-level
  targeting. Player overrides are disabled by default. TaCZ's own gun spread
  still applies.
- **Universal building datapack.** One optional ZIP contains Barracks, Village
  Armories, Sentry Posts, Watchtowers, and Training Yards for vanilla villages,
  ChoiceTheorem's Overhauled Village, Tidal Towns, Moog's Missing Villages, and
  Sky Villages. Install whichever village mods you want; content for absent
  providers stays inactive. Known absent providers no longer produce
  missing-pool warnings.

## Fixes

- Blocked or canceled SPAS-12 shots preserve ammo.
- Guards recheck firing safety when another mod changes nearby allies or blocks
  during a firing event. Changes to ammo or heat no longer cause supported
  scripted bullets to use different flight or explosion properties from those
  checked before firing.
- Guard status messages explain unsupported guns and safety-check limits.
  Outdated refusal messages clear after changes to targets, guns, or aim settings.
- Guards stop firing at creative and spectator players, including players who
  change game mode during a burst.

## Updating from 1.7

Back up important worlds and replace the mod JAR on both client and server.
Keep existing configuration files to preserve your settings, then restart.
Required dependency versions are unchanged.

The universal building datapack is a separate download. Install its ZIP in the
world's `datapacks` folder and enable Village Defense Building generation in
Fzzy Config. Remove overlapping individual or provider-specific building packs
before installing it. Restart the world or server before exploring new villages;
`/reload` alone does not apply building pool changes. Existing buildings remain
unchanged.

## Known limitations

Accuracy settings do not change gun damage or firing rate. Groups of guards can
still be difficult to fight. Custom gun packs with unusual firing scripts need
their own compatibility checks.

## Requirements

- Minecraft **1.20.1**, Java **17**, and Forge **47.4.10 or newer 47.x**.
- Guard Villagers **1.20.1-1.6.19**.
- Timeless and Classics Zero (TaCZ) **1.1.8-hotfix**.
- Fzzy Config **0.7.6 for Minecraft 1.20.1**.
- Kotlin for Forge **4.12.0**.

Install the mod and all four required dependencies on both client and server.
