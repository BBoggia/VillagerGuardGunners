# Villager Guard Gunners 1.9-neoforge-alpha.3

This update allows the Minecraft 1.21.1 NeoForge alpha to run on newer
NeoForge 21.1.x builds.

## Highlights

- Supports NeoForge 21.1.233 and newer 21.1.x builds, including 21.1.247 and
  21.1.264. The mod no longer requires exactly NeoForge 21.1.233.

## Updating

Replace the previous Villager Guard Gunners NeoForge jar on both client and
server. No configuration changes or companion datapack update are required
when upgrading from `1.9-neoforge-alpha.2`. Gameplay behavior is unchanged.

## Requirements

- **Minecraft:** 1.21.1
- **Java:** 21
- **NeoForge:** 21.1.233 or newer 21.1.x

The four dependency mods still require these exact versions:

- **Guard Villagers:** 2.4.12
- **Unofficial TaCZ NeoForge Port:** 1.1.8-hotfix-r7
- **Fzzy Config:** 0.7.7+1.21+neoforge
- **Kotlin for Forge:** 5.12.0

This remains an alpha release. Future NeoForge 21.1.x builds are allowed by
the version requirement, but have not been tested in advance.
