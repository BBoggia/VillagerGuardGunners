# Villager Guard Gunners 1.12

**Minecraft 1.20.1 · Forge · Beta**

Guards can now use MrCrayfish’s Gun Mod (Unofficial), Vic’s Point Blank, and Point Blank: Jelly. TaCZ is optional. You can keep using your existing TaCZ guards, add other supported guns to the same world, or use the village features without a gun mod.

## Highlights

- Equip a CGM or Point Blank gun and matching ammo in a guard’s inventory. Guards hold, aim, fire, and reload supported guns. Point Blank launchers are excluded.
- Natural guard loadouts, Rifleman and Medic kits, and Quartermaster offers include guns or ammo from the mods you install. Gun sales still start disabled. Newly generated Village Armories and Watchtowers also stock matching ammo, including a mix when multiple gun mods are installed.
- Guards with empty reserves can accept matching ammo from players, pickups, other guards, Armories, and Quartermasters. Guards can finish reloading during tactical movement. Switching guns or ending combat releases an interrupted reload.
- Creative ammo box mode gives new TaCZ loadouts a compatible box. CGM and Point Blank loadouts receive ordinary ammo. CGM guns configured for unlimited ammo skip unnecessary restock requests.

## Combat and compatibility

- CGM guards account for blast size and damage modifiers before firing. They recognize a standard grenade or missile even if an add-on assigns it to another ammo item, and hold fire with unfamiliar projectile types. Guard explosions protect allies and follow the block-protection setting.
- A canceled CGM projectile preserves its round. A shotgun that fires some of its pellets spends one shell.
- Point Blank guards follow the fire mode selected on the gun. A shot that has already fired spends a round even if an add-on interrupts its damage or sound effects. One model’s gun no longer affects the next model when a guard render is canceled or nested.
- Missing gun mods no longer use up the Quartermaster’s per-level trade allowance. If a new world starts with an invalid trade datapack, fix the pack and use `/reload` to restore offers on the same Quartermaster.

## Updating

Update the Forge jar on the server and each client. Existing TaCZ installations can keep their guns and ammo. Existing Village Armories keep their contents, and the companion Village Buildings datapack can stay in place.

## Requirements

Use Minecraft 1.20.1, Forge 47.4.10 or newer 47.x, Java 17, Guard Villagers 1.20.1-1.6.19, Fzzy Config 0.7.6 or newer 0.7.x, and Kotlin for Forge 4.12.0 (tested). If you use TaCZ, install the Forge build for 1.20.1, version 1.1.8 or newer.

For CGM, install Framework. For Point Blank, install GeckoLib and choose one variant. Vic’s Point Blank 1.9.6 and 2.2.0 and Point Blank: Jelly 2.1.0 passed the Forge combat checks. Vic’s Point Blank 1.3.3 can stay installed, but guards skip its guns.
