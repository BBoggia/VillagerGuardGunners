# Villager Guard Gunners 1.10

Stable release for Minecraft 1.20.1 Forge.

## Highlights

- Added four Infinite Ammo options: Off (default), with normal reloading,
  without reloading, and creative ammo boxes issued with new gun loadouts.
- Both virtual modes apply to existing and new guards without consuming carried
  supplies. Action cycling, firing delays, heat and friendly-fire protection remain active.
- Creative-box mode gives each new loadout weapon its matching TaCZ creative box.
  Existing guards can receive boxes manually. Issued boxes remain usable after
  changing modes and can be removed or transferred normally.
- Virtual ammo is reflected in guard ammo status, sidearm checks and resupply
  decisions. Guards skip automatic ammo pickup and Quartermaster ammo top-ups
  while using virtual reserves. Equipment and medical service remain available.

## Fixes

- Pending Quartermaster ammo deliveries are canceled when virtual Infinite Ammo
  is enabled, without moving stock or interrupting equipment and medical service.
- Quartermasters recognize compatible creative ammo boxes for each weapon and
  only request loose ammo for weapons that still need it. Removing a box restores
  ordinary resupply, even when the Infinite Ammo setting is Off.

## Updating

Replace the previous Forge JAR on client and server. Existing settings are
preserved. Select the mode in Fzzy Config under Ammo Quality of Life → Infinite
Ammo. The server controls the setting. Natural Gun Loadouts still controls the
chance of spawning with a gun. No companion datapack update is needed.

## Requirements

Minecraft 1.20.1, Java 17, Forge 47.4.10 or newer 47.x, Guard Villagers
1.20.1-1.6.19, TaCZ 1.1.8 or newer for 1.20.1, Fzzy Config 0.7.6 or 0.7.7
for Forge 1.20.1, and Kotlin for Forge 4.12.0 or compatible 4.x.
