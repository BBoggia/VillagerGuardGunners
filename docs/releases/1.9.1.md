# Villager Guard Gunners 1.9.1

Forge hotfix for Minecraft 1.20.1. This update fixes guards unnecessarily refusing
to fire certain weapons from community TaCZ gun packs.

## Highlights

- Guards can use more high-speed, long-lived, and wide-spread gun-pack weapons.
  Affected weapons include several guns from Elite X Quality Guns, Maxstuff's
  DB .50, and Daffa's Arsenal's M79.
- Guards can fire large-blast weapons such as the M79 in clear, dry surroundings.
  Nearby allies, unsafe impacts, water, and explosive fuses still affect whether
  a shot is safe.
- Friendly-fire protection remains active, including checks for allies beyond
  the target and checks before each round is fired.

## Updating

Replace the previous Villager Guard Gunners JAR on both client and server, then
restart. Keep your existing configuration files, worlds, and building datapacks.
No configuration reset or gun-pack edits are required.

## Requirements

- Minecraft **1.20.1**, Java **17**, and Forge **47.4.10 or newer 47.x**.
- Guard Villagers **1.20.1-1.6.19**.
- Timeless and Classics Zero (TaCZ) **1.1.8 or newer for Minecraft 1.20.1**.
- Fzzy Config **0.7.6 for Minecraft 1.20.1**.
- Kotlin for Forge **4.12.0**.

Install the mod and all four required dependencies on both client and server.
