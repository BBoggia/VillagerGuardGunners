# Villager Guard Gunners 1.12-neoforge

**Minecraft 1.21.1 · NeoForge · Beta**

You can now equip guards with guns from MrCrayfish’s Gun Mod (Unofficial), Vic’s Point Blank, or Point Blank: Jelly. Official TaCZ is optional. Guard Orders, squads, patrols, Quartermasters, and medical care also work in worlds with no gun mod.

## Highlights

- Guards aim, hold, fire, and reload supported CGM and Point Blank guns. They check for allies before firing. Point Blank support covers guns that hit their target directly. Guards hold fire with Point Blank launchers.
- Natural guard loadouts, Rifleman and Medic kits, and Quartermaster trades now include equipment for the installed gun mods. Ammo is available through supply trades. Server owners can enable gun sales separately.
- Guards with empty reserves again accept compatible rounds from players, dropped items, other guards, Village Armories, and Quartermasters. CGM guns set to native infinite ammo skip unnecessary supply requests.
- New CGM and Point Blank loadouts receive ordinary matching ammo when creative ammo boxes are enabled. TaCZ loadouts can still receive a compatible creative box.
- Newly generated Village Armories and Watchtowers stock ammo from all installed gun mods. Existing Armories keep their contents.
- Quartermaster trade limits exclude offers for absent gun mods. If a world starts with invalid trade data, repairing the datapack and using `/reload` restores offers on the same villager.

## Combat fixes

- CGM guard explosions protect allies and follow the block-protection setting. Guards account for grenade damage modifiers when checking whether a shot is safe.
- A canceled CGM projectile preserves its round. A shotgun that fires some of its pellets spends one shell.
- CGM and Point Blank guards can continue a reload while moving tactically. Ending combat or switching gun mods clears the interrupted reload. Inspecting a guard reports the gun it currently holds without interrupting its aim.
- CGM guards recognize grenade and missile projectiles reassigned to other ammo. They hold fire when a projectile is unfamiliar or changes after the friendly-fire check.
- Point Blank guards use the selected fire mode. A shot still spends a round if another mod interrupts the impact or sound. Guards skip incompatible Point Blank builds. Canceled or nested item renders correctly restore the previous holder.

## Updating

Install the new NeoForge jar on the server and each client. Existing TaCZ users can keep the official 1.2.0 build. You can keep the companion datapack for Minecraft 1.21.1.

## Requirements

Use Java 21, Guard Villagers 2.4.12, Kotlin for Forge 5.12.0, and either supported NeoForge Fzzy Config build (`0.7.7+1.21+neoforge` or `0.7.7+fix1+1.21+neoforge`).

The base mod supports NeoForge 21.1.233 or newer 21.1.x. If you add CGM 1.4.21, use **NeoForge 21.1.249 or newer** with **Framework 0.13.11 or newer**. For Point Blank, install GeckoLib and choose either Vic’s Point Blank 2.2.0 or Point Blank: Jelly 2.1.0. For TaCZ, use the official NeoForge 1.2.0 build.
