# Villager Guard Gunners 1.5

Version 1.5 brings armed Guard Villagers into newly generated villages with
optional biome-aware defense buildings, staffed positions, public ammo
storage, and improved structure designs.

<br>

## Highlights

<ul>
  <li>
    <strong>Village Defense Buildings</strong><br>
    Enable Barracks, public Village Armories, Sentry Posts, integrated Village
    Watchtowers, and Training Yards in newly generated plains, desert, savanna,
    snowy, and taiga villages. They don't replace vanilla or modded village
    buildings.<br><br>
  </li>
  <li>
    <strong>Difficulty-aware village garrisons</strong><br>
    Barracks, Sentry Posts, integrated Watchtowers, and Training Yards can
    create small guard groups. Guards can receive roles, squads, TaCZ guns, and
    matching ammo. Peaceful villages remain unstaffed, and server settings
    control the guard limits.<br><br>
  </li>
  <li>
    <strong>Purpose-built defensive positions</strong><br>
    Sentry guards remain near their roadside checkpoints. Integrated
    Watchtowers keep melee or unarmed guards in the ready room while guards
    carrying a TaCZ gun or crossbow take the upper deck. Training Yard targets
    are decorative and don't consume ammo.<br><br>
  </li>
  <li>
    <strong>Public village ammo stores</strong><br>
    Village Armory buildings include a public Village Armory with configurable
    ammo-only starting stock. Guards can restock there, and
    players can use hoppers, pipes, comparators, and the Armory inventory.<br><br>
  </li>
  <li>
    <strong>Reworked building designs</strong><br>
    Barracks, Village Armories, Sentry Posts, integrated Watchtowers, and
    Training Yards now have clearer entrances, usable interiors, supported
    lighting, biome-matched materials, and safer guard positions. Integrated
    Watchtowers add a roomier ready room, compact stairs, connected fence
    railings, and a taller observation opening.<br><br>
  </li>
  <li>
    <strong>Server and modpack controls</strong><br>
    Fzzy Config controls each building type, staffing, guard limits, gun
    chance, Village Armory placement, and initial stock. Datapacks can replace
    building entries, garrison groups, roles, loadout pools, and Armory stock.
    Permission-level-2 operators can inspect the loaded setup with
    <code>/vgg villagebuildings</code> commands.<br><br>
  </li>
</ul>

<br>

## Fixes

<ul>
  <li>
    Generated fences, iron bars, walls, stairs, doors, and similar blocks now
    connect correctly after biome selection and structure rotation.<br><br>
  </li>
  <li>
    Building entrances now remain open and meet their village road connector
    instead of becoming a solid biome block.<br><br>
  </li>
  <li>
    Decorative lanterns now retain valid support in every building style and
    rotation.<br><br>
  </li>
  <li>
    Interrupted building setup can recover guards and Village Armories without
    duplicating occupants, blocks, or starting supplies.<br><br>
  </li>
  <li>
    Completed buildings no longer replace removed guards, rebuild broken
    Village Armories, or reroll consumed starting stock when revisited.<br><br>
  </li>
</ul>

<br>

## Updating

<ul>
  <li>
    No world migration is required. Back up important worlds before updating.<br><br>
  </li>
  <li>
    Village Defense Buildings affect only newly generated villages. Existing
    village pieces are not changed.<br><br>
  </li>
  <li>
    The Village Defense Buildings master switch remains disabled by default.
    Server operators can enable <code>villageBuildings.enabled</code> through
    Fzzy Config, then restart the server before exploring new village terrain.<br><br>
  </li>
  <li>
    Standalone Village Watchtowers from version 1.4 remain independent from
    the new village-integrated Watchtowers.<br><br>
  </li>
</ul>

<br>

## Requirements

<ul>
  <li>Minecraft 1.20.1</li>
  <li>Forge 47.4.23</li>
  <li>Guard Villagers 1.20.1-1.6.19</li>
  <li>Timeless and Classics Zero 1.1.8-hotfix</li>
  <li>Fzzy Config 0.7.6 for Minecraft 1.20.1</li>
  <li>Kotlin for Forge 4.12.0</li>
</ul>

Install Villager Guard Gunners and every required dependency on both the
client and server.
