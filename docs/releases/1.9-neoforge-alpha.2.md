# Villager Guard Gunners 1.9-neoforge-alpha.2

This hotfix updates the Minecraft 1.21.1 NeoForge alpha.

## Highlights

- Fixed a firing-related crash when another TaCZ addon changes how shots are
  scheduled or projectiles are created. Guard friendly-fire protection remains
  active, and the other addon's firing behavior is preserved.

## Updating

Replace the previous Villager Guard Gunners NeoForge jar on both client and
server. No configuration changes or companion datapack update are required
when upgrading from `1.9-neoforge-alpha.1`.

## Requirements

Requires Minecraft 1.21.1, Java 21, and these exact versions:

- **NeoForge:** 21.1.233
- **Guard Villagers:** 2.4.12
- **Unofficial TaCZ NeoForge Port:** 1.1.8-hotfix-r7
- **Fzzy Config:** 0.7.7+1.21+neoforge
- **Kotlin for Forge:** 5.12.0

## Compatibility

This remains an alpha release. The fix addresses conflicting TaCZ firing
hooks; it does not guarantee compatibility with every gun pack or addon.
This fix does not make Forge-only addons compatible with NeoForge.
