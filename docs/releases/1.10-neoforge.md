# Villager Guard Gunners 1.10-neoforge

Stable release for Minecraft 1.21.1.

## Highlights

- Added an Infinite Ammo setting with four modes: Off, Infinite Ammo with
  Reloading, Infinite Ammo without Reloading, and Infinite Ammo with Creative
  Ammo Box. Off is the default.
- Both virtual modes apply to existing and new guards without consuming their
  carried supplies. Reloading mode keeps normal reload delays. No-reload mode
  keeps magazines supplied while retaining action cycling, heat, firing delays,
  and friendly-fire protection.
- Creative-box mode issues compatible TaCZ creative ammo boxes with new gun
  loadouts. Existing guards can be equipped manually. Removing the box restores
  normal ammo requirements once loaded rounds and other supplies run out.
- Added support for the Fzzy Config 0.7.7 hotfix while retaining support for the
  original 0.7.7 NeoForge build.
- Retains support for NeoForge 21.1.233 and newer 21.1.x builds, including 21.1.247.

## Fixes

- Pending Quartermaster ammo deliveries are canceled when virtual Infinite Ammo
  is enabled, without moving stock or interrupting equipment and medical service.
- Quartermasters recognize compatible creative ammo boxes for each weapon and
  only request loose ammo for weapons that still need it. Removing a box restores
  ordinary resupply, even when the Infinite Ammo setting is Off.

## Updating and configuration

Replace the previous NeoForge JAR on both client and server. Existing settings
are preserved, and Infinite Ammo starts Off. In Fzzy Config, open Villager Guard
Gunners → Ammo Quality of Life → Infinite Ammo. The server controls this setting.

Creative-box mode does not increase the chance of guards spawning with guns.
Use Natural Gun Loadouts to change that. Boxes already issued or supplied by
players remain usable when the setting is changed; they are ordinary TaCZ
items that can be removed and transferred. No companion datapack update is
needed when upgrading from the previous Minecraft 1.21.1 build.

## Requirements

- Minecraft 1.21.1, Java 21, and NeoForge 21.1.233 or newer 21.1.x.
- Guard Villagers 2.4.12.
- Unofficial TaCZ NeoForge Port 1.1.8-hotfix-r7.
- Fzzy Config `0.7.7+1.21+neoforge` or `0.7.7+fix1+1.21+neoforge`.
- Kotlin for Forge 5.12.0.

Use the Minecraft 1.21.1 NeoForge versions of the dependencies. This JAR is not
for Minecraft 1.20.1 Forge. Start a new world when moving from 1.20.1 because
the unofficial TaCZ port does not support its older world data.
