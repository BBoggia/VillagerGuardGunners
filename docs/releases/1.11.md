# Villager Guard Gunners 1.11

Compatibility update for Minecraft 1.20.1 and TaCZ 1.2.0.

## Highlights

- Fixed a crash when joining a world with TaCZ 1.2.0 caused by its changed
  gun-pack synchronization API.
- Use TaCZ 1.2.0's native compression and packet splitting. Older TaCZ versions
  retain the add-on's large-gun-pack synchronization workaround.
- Updated guard firing and draw timing to use the clock supplied by TaCZ when
  available, including single-player pause behavior.
- Updated firing hooks for TaCZ's new callbacks and post-fire events while
  retaining per-round friendly-fire checks and compatibility with other hooks.

## Updating

Replace the previous Villager Guard Gunners JAR on both client and server.
Existing configuration is preserved. This update retains older TaCZ support;
firing and ammo behavior were checked with TaCZ 1.1.8-hotfix2 and 1.2.0.
No companion Village Buildings datapack update is required for these fixes.
Use the separate NeoForge build for Minecraft 1.21.1.

## Requirements

- Minecraft 1.20.1 and Java 17.
- Forge 47.4.10 or newer 47.x.
- Guard Villagers 1.20.1-1.6.19.
- TaCZ 1.1.8 or newer for Forge 1.20.1.
- Fzzy Config 0.7.6 or 0.7.7 for Forge 1.20.1.
- Kotlin for Forge 4.12.0.
